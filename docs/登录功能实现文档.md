# 登录功能实现文档

## 功能概述

实现了微信一键登录功能，采用 **方案A+B混合** 的设计：
- **方案A**：微信登录无需授权，自动生成默认头像和昵称
- **方案B**：首次登录引导完善信息（可跳过）
- 用户随时可在个人中心修改头像和昵称

## 核心流程

### 1. 首次登录流程

```
用户打开小程序
    ↓
点击"微信一键登录"
    ↓
wx.login() 获取 code
    ↓
后端用 code 换取 openid
    ↓
后端判断是否为新用户
    ↓
新用户：生成默认头像和昵称
    ↓
返回：{ token, user, isNewUser: true }
    ↓
跳转到"完善信息"页面
    ↓
用户可以：
  - 上传头像 + 输入昵称 → 点击"完成"
  - 或直接点击"跳过"
    ↓
进入账本首页
```

### 2. 老用户登录流程

```
用户打开小程序
    ↓
点击"微信一键登录"
    ↓
wx.login() 获取 code
    ↓
后端验证用户已存在
    ↓
返回：{ token, user, isNewUser: false }
    ↓
直接进入账本首页
```

### 3. 修改个人信息流程

```
进入"我的"页面
    ↓
方式1：点击头像区域 → 选择图片 → 上传
方式2：点击"昵称"菜单项 → 输入新昵称 → 保存
    ↓
调用后端API更新
    ↓
更新本地缓存和全局状态
```

## 核心代码说明

### 1. app.js - 全局状态管理

```javascript
App({
  globalData: {
    user: null,      // 当前用户信息
    token: '',       // 登录凭证
  },
  
  // 保存登录态
  setLoginState(token, user) {
    this.globalData.token = token
    this.globalData.user = user
    wx.setStorageSync('token', token)
    wx.setStorageSync('user', user)
  },
  
  // 清除登录态
  clearLoginState() {
    this.globalData.token = ''
    this.globalData.user = null
    wx.removeStorageSync('token')
    wx.removeStorageSync('user')
  }
})
```

### 2. 登录页面 - login.js

```javascript
async handleWechatLogin() {
  // 1. 获取微信登录凭证
  const { code } = await wx.login()
  
  // 2. 调用后端登录接口
  const res = await request({
    url: '/auth/login',
    method: 'POST',
    data: { code }
  })
  
  // 3. 保存登录信息
  const { token, user, isNewUser } = res
  app.setLoginState(token, user)
  
  // 4. 首次登录 → 完善信息页，否则 → 账本页
  if (isNewUser) {
    wx.redirectTo({ url: '/pages/profile-setup/index' })
  } else {
    wx.switchTab({ url: '/pages/books/books' })
  }
}
```

### 3. 完善信息页 - profile-setup/index.js

**核心功能：**
- 上传头像到服务器
- 输入昵称
- 点击"完成"保存或"跳过"使用默认信息

```javascript
// 上传头像
chooseAvatar() {
  wx.chooseMedia({
    count: 1,
    mediaType: ['image'],
    sizeType: ['compressed'],
    success: (res) => {
      const tempFilePath = res.tempFiles[0].tempFilePath
      this.uploadAvatar(tempFilePath)
    }
  })
}

// 完成
async onComplete() {
  await request({
    url: '/user/profile',
    method: 'PUT',
    data: { avatar, nickname }
  })
  
  // 更新本地信息
  user.avatar = avatar
  user.nickname = nickname
  user.isProfileComplete = true
  
  app.globalData.user = user
  wx.setStorageSync('user', user)
  
  wx.switchTab({ url: '/pages/books/books' })
}
```

## 后端接口要求

### 1. 登录接口

**POST** `/auth/login`

**请求：**
```json
{
  "code": "微信登录凭证"
}
```

**响应：**
```json
{
  "code": 200,
  "data": {
    "token": "jwt_token",
    "isNewUser": true,  // 是否首次登录
    "user": {
      "id": 1001,
      "openid": "oXXXX",
      "avatar": "https://cdn.xxx.com/default_1.png",
      "nickname": "用户1234",
      "isProfileComplete": false
    }
  }
}
```

**后端逻辑：**
1. 用 code 换取 openid（调用微信接口）
2. 查询数据库是否存在该 openid
3. 不存在：创建新用户，生成默认头像和昵称
4. 存在：返回用户信息
5. 生成 JWT token

### 2. 更新个人信息接口

**PUT** `/user/profile`

**请求头：**
```
Authorization: Bearer {token}
```

**请求：**
```json
{
  "avatar": "https://cdn.xxx.com/avatar/xxx.jpg",
  "nickname": "新昵称"
}
```

**响应：**
```json
{
  "code": 200,
  "message": "更新成功"
}
```

### 3. 上传头像接口

**POST** `/upload/avatar`

**请求头：**
```
Authorization: Bearer {token}
Content-Type: multipart/form-data
```

**请求：**
```
FormData:
  file: [图片文件]
```

**响应：**
```json
{
  "code": 200,
  "data": {
    "url": "https://cdn.xxx.com/avatar/xxx.jpg"
  }
}
```

## 默认头像和昵称生成规则

### 后端实现（Node.js示例）

```javascript
// 生成默认头像
function generateDefaultAvatar() {
  const colors = ['#FF6B9D', '#4097a9', '#5B8CFF', '#FFB84D', '#4ECDC4']
  const randomColor = colors[Math.floor(Math.random() * colors.length)]
  
  // 方案1：返回预设的彩色占位符图片URL
  return `https://cdn.xxx.com/avatar/default_${randomColor.slice(1)}.png`
  
  // 方案2：使用头像生成服务（UI Avatars等）
  // return `https://ui-avatars.com/api/?background=${randomColor.slice(1)}&color=fff&size=200`
}

// 生成默认昵称
function generateDefaultNickname() {
  const random = Math.floor(Math.random() * 10000)
  return `用户${random.toString().padStart(4, '0')}`
}
```

## 注意事项

1. **隐私合规**：
   - 不直接获取微信头像和昵称
   - 用户主动上传头像和输入昵称
   - 符合微信隐私政策要求

2. **数据同步**：
   - 修改信息后要同步更新：
     - `app.globalData.user`
     - `wx.setStorageSync('user', user)`
   - 个人中心页面在 `onShow` 时刷新数据

3. **图片上传**：
   - 前端压缩图片（`sizeType: ['compressed']`）
   - 后端验证文件类型和大小
   - 推荐上传到云存储（Cloudflare R2 / 阿里云 OSS）

4. **错误处理**：
   - 登录失败：提示用户重试
   - 上传失败：保留原头像
   - 网络错误：友好提示
