# 出发AA记账 - Stitch UI 设计提示词

## 项目概述
**产品名称：** 出发AA记账 / DepartureAA  
**产品定位：** 多人场景记账应用，专注于旅行、聚餐、活动等多人分账场景  
**目标用户：** 18-35岁年轻群体，喜欢旅行、社交、注重生活品质

---

## 设计风格要求

### 整体风格
- **视觉风格：** 年轻活力、圆润可爱、像素艺术元素
- **设计特点：** 多使用插画贴图、异形卡片、增强设计感
- **圆角标准：** 所有卡片使用大圆角（24-32px），按钮使用圆角（16-20px）
- **界面布局：** 清晰明了，信息层级分明，减少用户思考成本

### 配色方案
基于提供的配色卡设计：

**主色调：**
- **主色（高级蓝）：** `#4097a9` - 用于主要按钮、标题、重要信息
- **辅助色（配色米）：** `#f4dfcc` - 用于卡片背景、辅助信息区域
- **强调色（高级感粉）：** `#fa9583` - 用于重要操作按钮、强调信息
- **深色（高级感深蓝）：** `#2f4159` - 用于文字、图标、导航栏

**功能色：**
- **支出色：** `#fa9583`（粉橙色）
- **收入色：** `#4097a9`（蓝绿色）
- **私密账标识：** `#2f4159`（深蓝色）+ 🔒图标

**背景渐变：**
- 主背景使用柔和渐变：从 `#e8f4f8` 到 `#fef5ed`
- 卡片使用半透明白色背景 `rgba(255, 255, 255, 0.9)` 或米色 `#f4dfcc`

### 设计元素
1. **插画贴图：** 在空状态、引导页、账本封面使用手绘风格插画
2. **异形卡片：** 不规则圆角卡片、波浪边框卡片、带装饰图案的卡片
3. **图标风格：** 圆润线性图标，线条粗细2-3px
4. **阴影效果：** 柔和阴影 `0 4px 20px rgba(47, 65, 89, 0.08)`

### 间距系统（8px Grid）
- **xs (4px)：** 图标与文字间距、小型元素间距
- **sm (8px)：** 组件内元素间距、列表项内部间距
- **md (16px)：** 卡片内边距、表单元素间距
- **lg (24px)：** 卡片外边距、页面左右边距
- **xl (32px)：** 大区块间距、页面顶部间距
- **2xl (48px)：** 页面section间距

**常用间距应用：**
- 卡片内边距：16px（上下左右）
- 卡片间距：12px
- 页面左右边距：16px
- 列表项高度：56-64px
- 顶部安全区：44px（导航栏）+ 16px = 60px
- 底部安全区：34px（刘海屏）+ 56px（Tab栏）= 90px

### 字体规范
**字体家族：**
- **iOS：** PingFang SC（苹方）
- **Android：** Noto Sans CJK SC（思源黑体）
- **Fallback：** system-ui, -apple-system, sans-serif

**字重定义：**
- **Regular：** 400 - 正文、辅助文字
- **Medium：** 500 - 标题、重要信息
- **Semibold：** 600 - 小标题
- **Bold：** 700 - 大标题、强调数字

## 组件库

### 按钮组件

**主按钮（Primary Button）**
- **默认：** 背景 `#fa9583`，白色文字16px Medium，圆角16px，内边距12px 24px
- **按下：** 背景 `#e8856f`（深10%），轻微缩放0.98，阴影减弱
- **禁用：** 背景 `#fad4cc`，文字 `#c4c4c4`，透明度0.5，无阴影
- **阴影：** `0 2px 8px rgba(250, 149, 131, 0.3)`

**次要按钮（Secondary Button）**
- **默认：** 边框1px `#4097a9`，文字 `#4097a9` 16px Medium，背景透明，圆角16px
- **按下：** 背景 `rgba(64, 151, 169, 0.08)`
- **禁用：** 边框 `#c4c4c4`，文字 `#c4c4c4`

**文字按钮（Text Button）**
- **默认：** 文字 `#4097a9` 16px Medium，无背景无边框
- **按下：** 文字 `#3a8599`（深10%）
- **禁用：** 文字 `#c4c4c4`

**大型操作按钮（FAB - Floating Action Button）**
- **尺寸：** 56x56px圆形
- **背景：** 渐变 `linear-gradient(135deg, #fa9583 0%, #ff6b9d 100%)`
- **图标：** 白色"+" 32x32px
- **阴影：** `0 4px 12px rgba(250, 149, 131, 0.4)`
- **按下：** 缩放0.95，阴影扩大到16px

### 输入框组件

**文本输入框（Text Input）**
- **默认：** 
  - 边框1px `#e5e5e5`，圆角12px
  - 背景白色，内边距12px 16px
  - placeholder文字 `#c4c4c4` 16px Regular
- **聚焦：** 边框2px `#4097a9`，背景保持白色
- **错误：** 边框2px `#fa9583`，底部显示错误提示文字12px `#fa9583`
- **禁用：** 背景 `#f5f5f5`，文字 `#c4c4c4`，边框 `#e5e5e5`

**金额输入框（Amount Input）**
