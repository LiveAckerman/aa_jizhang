**整体风格：**
- 扁平化设计
- 圆润可爱
- 色彩鲜明

- 辅助色：#FFB84D（橙黄色）

## 使用建议

### 1. 使用 AI 图像生成工具

推荐工具：
- **Midjourney**（质量最高）
- **DALL-E 3**（OpenAI）
- **Stable Diffusion**（开源）
- **Leonardo.ai**（免费额度）

### 2. 生成后处理

1. 使用 Figma 或 Photoshop 调整尺寸为 512x512px
2. 确保背景透明（PNG格式）
3. 如果颜色不准，使用取色工具调整为指定色值
4. 保存到 `/packages/miniapp/assets/` 目录

### 3. 文件命名

```
feature-multi.png     # 多人记账
feature-smart.png     # 智能分账
feature-secure.png    # 安全可靠
```

## 临时替代方案（使用 emoji）

如果暂时无法生成 AI 图标，可以先使用 emoji 作为临时方案：

修改 `login.wxml`：

```xml
<!-- 临时使用 text 代替 image -->
<view class="feature-icon-box">
  <text class="feature-emoji">👥</text>
</view>
```

对应的 CSS：

```css
.feature-emoji {
  font-size: 56rpx;
}
```

emoji 对应：
- 多人记账：👥 或 👨‍👩‍👧‍👦
- 智能分账：💰 或 🧮
- 安全可靠：🔒 或 🛡️
