# 出发AA记账 - UI设计简要文档

## 项目信息

**产品名称：** 出发AA记账 / DepartureAA  
**设计版本：** v1.0  
**目标平台：** iOS / Android 移动应用  
**设计基准：** iPhone X (375x812)

---

## 设计理念

**核心概念：** 像素风 + 星空元素 + 年轻活力

将记账这件事情变得有趣和温暖，用星空和旅行的意象传达「每一次出发都值得记录」的品牌理念。

**关键词：**
- 🌌 梦幻星空
- 🎨 像素艺术
- 🌈 渐变色彩
- ✨ 活力年轻
- 🎪 趣味插画

---

## 配色方案

### 主色调：星空渐变系

**灵感来源：** 星空夜景 - 从深蓝夜空到橙粉晚霞

**核心色彩：**
- **深夜蓝：** `#2f4159` - 导航栏、深色文字、图标
- **星空蓝：** `#4097a9` - 主要操作、品牌色、强调元素
- **晚霞粉橙：** `#fa9583` - 重要按钮、警示、支出
- **温暖米色：** `#f4dfcc` - 卡片背景、辅助区域

**渐变背景：**
```
主背景渐变：从浅蓝到浅米黄，营造温暖氛围
卡片渐变：半透明白色叠加，毛玻璃效果
特殊卡片：星空渐变（深蓝→青色→粉橙），加入星星装饰
```

**功能色：**
- 支出：粉橙色系
- 收入：蓝绿色系
- 私密：深蓝 + 🔒
- 共享：蓝绿 + 👥

---

## 视觉风格

### 整体风格：像素风格 + 现代设计

**元素特征：**
1. **像素化装饰：** 
   - 星星、云朵、装饰图案使用像素风格
   - 复古游戏感，增加趣味性
   
2. **异形卡片：**
   - 不规则圆角（波浪边、贴纸装饰）
   - 让界面更有设计感和活力
   
3. **扁平插画：**
   - 简化的几何图形
   - 场景插画（旅行、聚餐、合租）
   - 空状态使用温暖的手绘风格

4. **星空元素：**
   - 背景中点缀小星星✨
   - 头部卡片使用星空渐变背景
   - 装饰性的流星、云朵

### 圆角规范
- **大圆角：** 所有主要卡片使用大圆角（让界面更柔和）
- **中圆角：** 按钮、输入框
- **小圆角：** 标签、徽章
- **完全圆形：** 头像、FAB按钮、某些图标按钮

## 核心页面布局

### 1. 账本列表页（首页）

**顶部区域：**
- 深色导航栏，品牌名称 + logo
- 搜索和创建按钮

**统计卡片：**
- 异形卡片（波浪顶部边框）
- 本月支出 | 待结算金额
- 使用渐变背景

**账本列表：**
- 自定义分组：用户自建分组的可折叠分区（未归组归入「未分组」），长按标题可重命名/删除
- 状态分组：进行中 / 已结算（自动，与自定义分组正交）
- 每个账本卡片：
  - 场景emoji或插画
  - 账本名称
  - 成员头像（重叠排列）
  - 金额信息
  - 进度条（可选）
  - 渐变边框（进行中的账本）

**底部Tab：**
- 4个Tab，中间是凸起的圆形记账按钮
- 渐变色大按钮，向上凸起
- 毛玻璃效果背景

---

### 2. 账本详情页

**头部卡片：**
- **星空渐变背景** + 场景插画

**账单流水：**
- 时间线风格
- 按日期分组
- 共享账单：浅色背景 + 👥图标
- 私密账单：深色背景 + 🔒图标

**底部固定按钮：**
- 大型主按钮"记一笔"
- 使用粉橙色

## 核心功能的视觉呈现

### 双账本模式（核心差异化）

**视觉区分非常明显：**

**共享账：**
- 👥 图标
- 浅色背景（白色/浅蓝）
- 显示参与人员信息
- 显示分摊方式

**私密账：**
- 🔒 图标
- 深色背景（深蓝灰）
- 标注"仅自己可见"
- 不显示分摊信息

**切换器：**
- 顶部明显位置
- Tab样式，背景滑动动画
- 选中态使用品牌蓝色，白色文字

## 设计原则

1. **简单易用** - 减少用户思考成本，操作流程简洁
2. **视觉焦点** - 每个页面有明确的视觉焦点
3. **反馈及时** - 所有操作都有明确的视觉反馈
4. **一致性** - 统一的设计语言和交互模式
5. **情感化** - 温暖友好的视觉体验
