# 全局按钮优化说明

## 问题描述

小程序中的 `.btn-primary` 按钮在点击时会出现底色变白的问题，影响用户体验。同时缺少明确的加载状态提示。

## 解决方案

### 1. 全局样式优化 (app.wxss)

#### 按钮点击态
```css
/* 按钮按下态:防止变白 */
.btn-primary:active {
  opacity: 0.8;
  background: var(--color-accent);
}
```

#### 按钮禁用态
```css
/* 按钮禁用态 */
.btn-primary:disabled,
.btn-primary[disabled] {
  opacity: 0.6;
  background: var(--color-accent);
}
```

#### Loading 状态样式
```css
/* 按钮 loading 状态 */
.btn-primary.loading {
  opacity: 0.8;
}

/* 按钮内 loading spinner (纯CSS) */
.btn-loading-icon {
  display: inline-block;
  width: 32rpx;
  height: 32rpx;
  margin-right: 12rpx;
  vertical-align: -6rpx;
  border: 4rpx solid rgba(255, 255, 255, 0.3);
  border-top-color: #ffffff;
  border-radius: 50%;
  animation: btn-rotate 0.6s linear infinite;
}

@keyframes btn-rotate {
  from { transform: rotate(0deg); }
  to { transform: rotate(360deg); }
}
```

### 2. WXML 模板优化

#### 带 loading 状态的按钮
```html
<button
  class="btn-primary save-btn {{saving ? 'loading' : ''}}"
  bindtap="onSave"
  disabled="{{saving}}"
  hover-class="none"
>
  <view wx:if="{{saving}}" class="btn-loading-icon"></view>
  {{saving ? '保存中...' : '保存'}}
</button>
```

#### 普通按钮（不需要 loading）
```html
<button class="btn-primary" bindtap="onClick" hover-class="none">
  按钮文本
</button>
```

**关键点:**
- 添加 `hover-class="none"` 禁用微信默认的点击态
- Loading 状态时添加 `loading` class
- 使用 `<view class="btn-loading-icon"></view>` 显示 CSS 旋转动画

### 3. JS 逻辑优化

#### 标准保存/提交流程
```javascript
async onSave() {
  // 表单验证...
  if (this.data.saving) return
  
  this.setData({ saving: true })
  wx.showLoading({ title: '保存中...', mask: true })
  
  try {
    await api.someAction(payload)
    wx.hideLoading()
    wx.showToast({ title: '已保存', icon: 'success' })
    setTimeout(() => wx.navigateBack(), 600)
  } catch (e) {
    wx.hideLoading()
    wx.showToast({ title: e.message || '保存失败', icon: 'none' })
    this.setData({ saving: false })
  }
}
```

**关键点:**
- 使用 `wx.showLoading()` 显示全局加载提示
- 成功/失败都要调用 `wx.hideLoading()` 关闭
- 失败时重置 `saving` 状态，成功时不重置（因为会页面跳转）

## 最佳实践

### 何时使用 loading 状态
- ✅ 表单保存/提交
- ✅ 数据创建/更新/删除
- ✅ 网络请求操作
- ❌ 页面内导航跳转
- ❌ 纯展示类按钮

### 何时使用 wx.showLoading
- ✅ 异步操作预期时间 > 500ms
- ✅ 需要阻止用户其他操作时
- ✅ 关键业务流程（创建/保存/支付等）
- ❌ 快速查询操作
- ❌ 后台刷新数据

### Loading 文案规范
- 保存操作: "保存中..."
- 创建操作: "创建中..."
- 加入操作: "加入中..."
- 上传操作: "上传中..."
- 处理操作: "处理中..."

## 技术细节

### 为什么使用纯 CSS spinner
1. **无需图片资源** - 减小包体积
2. **自适应主题色** - 使用白色边框，适配品牌色按钮
3. **性能好** - CSS 动画比 image 组件性能更好
4. **易维护** - 全局统一样式，修改一处即生效

### 为什么禁用 hover-class
微信小程序 button 的默认 hover 效果会覆盖背景色，导致:
- 点击时背景变成浅灰色
- 破坏品牌色视觉一致性
- 影响用户体验

使用 `hover-class="none"` + CSS `:active` 伪类可以:
- 保持品牌色
- 提供视觉反馈（opacity 变化）
- 更好的控制力

### 测试场景
1. **正常流程** - 填写表单 → 点击保存 → 成功提示 → 页面跳转
2. **网络失败** - 关闭网络 → 点击保存 → 失败提示 → 按钮恢复可点击
3. **快速点击** - 快速连续点击按钮 → 只触发一次请求
4. **页面返回** - 保存过程中返回上一页 → 请求正常取消

## 后续优化建议

1. **抽象为组件** - 将带 loading 的按钮封装为通用组件
2. **统一 API 调用** - 封装统一的请求方法，自动处理 loading 状态
3. **防抖节流** - 对于不需要禁用的按钮，添加防抖处理
4. **键盘优化** - 表单页面支持回车触发保存
