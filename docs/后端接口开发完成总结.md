# 后端接口开发完成总结

## ✅ 已完成的功能

### 1. 登录认证接口

#### POST `/api/auth/login`
**功能：** 微信登录，支持首次登录判断

**请求体：**
```json
{
  "code": "微信登录code"
}
```

**响应：**
```json
{
  "code": 200,
  "message": "登录成功",
  "data": {
    "token": "jwt_token_string",
    "isNewUser": true,  // 是否首次登录或信息未完善
    "user": {
      "id": "uuid",
      "openid": "wx_openid",
      "unionid": "wx_unionid",
      "nickname": "用户1234",  // 默认昵称
      "avatar": "https://cdn.ljw44.com/avatar/default.png",  // 默认头像
      "isProfileComplete": false,
      "createdAt": "2026-08-13T10:00:00Z",
      "updatedAt": "2026-08-13T10:00:00Z"
    }
  }
}
```

**核心逻辑：**
1. 用微信 code 换取 openid
2. 查询数据库是否存在该用户
3. 首次登录：创建用户 + 生成默认头像和昵称 + 返回 `isNewUser: true`
4. 老用户：如果 `isProfileComplete = false`，也返回 `isNewUser: true`
5. 签发 JWT token

---

### 2. 用户信息更新接口

#### PUT `/api/user/profile`
**功能：** 更新用户头像和昵称

**请求头：**
```
Authorization: Bearer {token}
```

**请求体：**
```json
{
  "nickname": "新昵称",
  "avatar": "https://cdn.ljw44.com/avatar/xxx.png"
}
```

**响应：**
```json
{
  "code": 200,
  "message": "更新成功",
  "data": {
    "id": "uuid",
    "nickname": "新昵称",
    "avatar": "https://cdn.ljw44.com/avatar/xxx.png",
    "isProfileComplete": true,  // 自动标记为已完善
    "updatedAt": "2026-08-13T10:05:00Z"
  }
}
```

**核心逻辑：**
1. 验证 JWT token
2. 更新用户信息
3. 自动设置 `isProfileComplete = true`

---

### 3. 头像上传接口

#### POST `/api/upload/avatar`
**功能：** 上传头像到 Cloudflare R2

**请求头：**
```
Authorization: Bearer {token}
Content-Type: multipart/form-data
```

**请求体：**
```
file: 图片文件
```

**文件限制：**
- 支持格式：jpg、png、webp
- 最大大小：5MB

**响应：**
```json
{
  "code": 200,
  "message": "上传成功",
  "data": {
    "url": "https://cdn.ljw44.com/avatar/uuid-xxx.png"
  }
}
```

**核心逻辑：**
1. 验证 JWT token
2. 验证文件类型和大小
3. 生成唯一文件名（使用 uuid）
4. 上传到 Cloudflare R2
5. 返回公开访问 URL

## 🔄 数据流程

### 首次登录流程

```
小程序端                              后端                              数据库
   |                                   |                                   |
   |-- wx.login() 获取 code ---------->|                                   |
   |                                   |-- 调用微信 API 换取 openid ------>|
   |                                   |<-- 返回 openid -------------------|
   |                                   |                                   |
   |                                   |-- 查询用户 SELECT * FROM user --->|
   |                                   |<-- 用户不存在 --------------------|
   |                                   |                                   |
   |                                   |-- 生成默认头像和昵称               |
   |                                   |-- INSERT INTO user --------------->|
   |                                   |<-- 插入成功 ----------------------|
   |                                   |                                   |
   |                                   |-- 签发 JWT token                   |
   |<-- 返回 token + isNewUser:true ---|                                   |
   |                                   |                                   |
   |-- 判断 isNewUser == true          |                                   |
   |-- 跳转到完善信息页                 |                                   |
```

### 上传头像 + 更新信息流程

```
小程序端                              后端                              Cloudflare R2
   |                                   |                                   |
   |-- 选择图片 ---------------------->|                                   |
   |-- POST /api/upload/avatar ------->|                                   |
   |   (携带 token)                    |-- 验证 token                       |
   |                                   |-- 验证文件类型和大小                |
   |                                   |-- 生成唯一文件名 (uuid)             |
   |                                   |-- 上传到 R2 --------------------->|
   |                                   |<-- 返回公开 URL -------------------|
   |<-- 返回图片 URL ------------------|                                   |
   |                                   |                                   |
   |-- PUT /api/user/profile --------->|                                   |
   |   { avatar, nickname }            |-- 更新数据库                       |
   |                                   |-- 设置 isProfileComplete = true    |
   |<-- 更新成功 ----------------------|                                   |
   |                                   |                                   |
   |-- 跳转到账本首页                   |                                   |
```

## ⚠️ 注意事项

### 1. Cloudflare R2 配置
- 需要在 Cloudflare 控制台创建 R2 存储桶
- 需要配置自定义域名绑定（cdn.ljw44.com）
- 需要生成 API 密钥（Access Key ID + Secret Access Key）

### 2. 默认头像生成策略
当前实现：返回固定的默认头像 URL

**可选优化方案：**
- 使用 Gravatar 生成默认头像
- 使用 DiceBear API 生成卡通头像
- 自己生成彩色占位符图片

### 3. 安全性建议
- 生产环境务必更换 JWT_SECRET
- 微信 AppSecret 不要提交到 Git
- R2 密钥不要泄露
- 添加请求频率限制（防止恶意上传）
