## 🎯 核心流程

### 首次登录流程
```
1. 用户点击"微信一键登录"
   ↓
2. wx.login() 获取 code
   ↓
3. 后端验证 code，返回 { token, user, isNewUser: true }
   ↓
4. 保存 token 和 user 到本地缓存和全局状态
   ↓
5. 跳转到完善信息页
   ↓
6. 用户可以：
   - 上传头像 + 输入昵称 + 点击"完成"
   - 或直接点击"跳过"
   ↓
7. 进入账本首页
```

### 老用户登录流程
```
1. 用户点击"微信一键登录"
   ↓
2. wx.login() 获取 code
   ↓
3. 后端验证 code，返回 { token, user, isNewUser: false }
   ↓
4. 保存 token 和 user
   ↓
5. 直接进入账本首页
```

### 修改个人信息流程
```
进入个人中心
   ↓
方式1：点击头像 → 选择图片 → 上传
方式2：点击昵称 → 输入新昵称 → 保存
   ↓
调用后端 API 更新
   ↓
更新本地缓存和全局状态
```

## 🔌 后端接口要求

### 1. POST /auth/login
**请求：**
```json
{ "code": "微信登录凭证" }
```

**响应：**
```json
{
  "code": 200,
  "data": {
    "token": "jwt_token",
    "isNewUser": true,
    "user": {
      "id": 1001,
      "openid": "oXXXX",
      "avatar": "https://cdn.xxx.com/default_1.png",
      "nickname": "用户1234",
      "isProfileComplete": false
    }
  }
}
```

### 2. PUT /user/profile
**请求头：**
```
Authorization: Bearer {token}
```

**请求：**
```json
{
  "avatar": "https://cdn.xxx.com/avatar/xxx.jpg",
  "nickname": "新昵称"
}
```

**响应：**
```json
{
  "code": 200,
  "message": "更新成功"
}
```

### 3. POST /upload/avatar
**请求头：**
```
Authorization: Bearer {token}
Content-Type: multipart/form-data
```

**请求：**
```
FormData: file (图片文件)
```

**响应：**
```json
{
  "code": 200,
  "data": {
    "url": "https://cdn.xxx.com/avatar/xxx.jpg"
  }
}
```

## 📝 注意事项

1. **微信隐私政策合规**
   - 不直接获取微信头像和昵称
   - 用户主动上传和输入
   - 符合最新微信规范

2. **数据同步**
   - 修改信息后同步更新 `app.globalData.user`
   - 同步更新 `wx.setStorageSync('user', user)`
   - 个人中心页面在 `onShow` 时刷新

3. **图片上传**
   - 前端压缩图片（`sizeType: ['compressed']`）
   - 后端需要验证文件类型和大小
   - 推荐上传到 Cloudflare R2（已配置）

4. **错误处理**
   - 所有网络请求都有 try-catch
   - 失败时显示友好提示
   - 上传失败保留原头像
