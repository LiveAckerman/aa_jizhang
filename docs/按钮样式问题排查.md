# 按钮样式问题排查

## 问题现象

按钮在点击时背景和文字都变成白色，导致完全看不见按钮内容。

## 根本原因分析

### 问题 1：全局 button 重置导致背景透明

最初为了覆盖微信原生样式，在全局样式中设置了：
```css
button {
  background: transparent !important;
}
```

这导致所有没有设置 `!important` 的自定义按钮样式都失效，背景变成透明。

### 问题 2：微信小程序原生 hover 效果

微信小程序的 `<button>` 组件有以下几个默认行为：

1. **原生 hover 效果** - 即使设置了 `hover-class="none"`，仍然可能有原生的点击态样式
2. **button::after 伪元素** - 微信会添加一个 `::after` 伪元素用于边框和点击态效果
3. **CSS 优先级** - 微信的原生样式优先级可能高于自定义样式
4. **组件框架** - 项目使用了 `glass-easel` 组件框架和 `@vant/weapp`，可能有额外的样式影响

## 解决方案

### 1. 全局 button 重置（不设置 background）

```css
/* ✅ 正确：只重置 padding、border 等，不强制设置 background */
button {
  padding: 0 !important;
  margin: 0 !important;
  line-height: inherit !important;
  box-sizing: border-box !important;
  border: none !important;
}

button::after {
  border: none !important;
  background: none !important;
}
```

**关键点：**
- ❌ 不要设置 `background: transparent !important` - 会导致所有按钮背景失效
- ✅ 让每个按钮自己定义背景色

### 2. 使用 button 元素选择器提高优先级

```css
/* 使用 button.btn-primary 而不是 .btn-primary */
button.btn-primary {
  background-color: #fa9583 !important;
  background: #fa9583 !important;
  color: #ffffff !important;
  /* ... */
}
```

**为什么这样做：**
- `button.btn-primary` 的优先级 (0,0,1,1) 高于 `.btn-primary` (0,0,1,0)
- 覆盖微信原生 `button` 元素的默认样式

### 3. 覆盖所有可能的状态

```css
/* 正常态 */
button.btn-primary { }

/* 点击态 */
button.btn-primary:active,
button.btn-primary:hover,
button.btn-primary:focus { }

/* 禁用态 */
button.btn-primary:disabled,
button.btn-primary[disabled],
button.btn-primary[disabled]:active { }

/* button-hover 类（微信默认） */
button.btn-primary.button-hover { }

/* 伪元素 */
button.btn-primary::before,
button.btn-primary::after { }
```

### 4. 所有自定义按钮都要添加 !important

项目中所有自定义按钮样式都需要添加 `!important` 来确保不被全局样式覆盖：

```css
/* book-detail 页面的按钮 */
.record-btn.manual {
  background: var(--color-accent) !important;
  color: #fff !important;
}

.record-btn.ocr {
  background: rgba(64, 151, 169, 0.1) !important;
  color: var(--color-primary) !important;
  border: 2rpx solid var(--color-primary) !important;
}

/* settle-detail 页面的按钮 */
.settle-btn {
  background: var(--color-primary) !important;
  color: #fff !important;
}

/* 其他页面的自定义按钮也需要类似处理 */
```

**已修复的按钮：**
- ✅ `.btn-primary` - 主按钮（全局）
- ✅ `.record-btn.manual` / `.record-btn.ocr` - book-detail 页面
- ✅ `.settle-btn` - settle-detail 页面
- ✅ `.round-new-btn` - book-detail 结算按钮
- ✅ `.btn-back` - ocr-batch-edit 页面
- ✅ `.btn-preview` - settle-select 页面
- ✅ `.clear-search-btn` - books 页面

### 5. WXML 中设置 hover-class="none"

```html
<button class="btn-primary" hover-class="none">
  按钮文本
</button>
```

## 检查清单

如果按钮仍然出现样式问题，按以下顺序检查：

### 1. 检查 WXML
- [ ] 是否设置了 `hover-class="none"`
- [ ] class 名称是否正确 `btn-primary`
- [ ] 是否有其他 class 冲突

### 2. 检查全局样式 (app.wxss)
- [ ] button 重置样式是否生效
- [ ] button.btn-primary 选择器是否正确
- [ ] 所有状态（:active, :disabled 等）是否都有样式
- [ ] 是否使用了 !important

### 3. 检查局部样式
- [ ] 页面的 .wxss 文件是否有覆盖 .btn-primary 的样式
- [ ] 是否有其他更高优先级的选择器

### 4. 检查组件库
- [ ] 是否引入了 vant 或其他组件库的全局样式
- [ ] 组件库样式是否影响了 button

### 5. 真机测试
- [ ] 开发工具中正常但真机异常 - 可能是编译问题
- [ ] 尝试清除缓存重新编译
- [ ] 检查微信开发者工具的 "不校验合法域名" 是否影响

## 调试方法

### 方法 1：使用微信开发者工具审查元素

1. 右键点击按钮 → "审查元素"
2. 查看 Computed 面板，看实际生效的样式
3. 查看哪些样式被覆盖（有删除线）

### 方法 2：临时修改样式验证

在页面的 .wxss 中添加：

```css
.save-btn {
  background: red !important;
  color: white !important;
}
```

如果红色生效，说明是样式优先级问题。如果还是白色，说明有更强的样式覆盖。

### 方法 3：使用 view 模拟按钮

如果所有方法都失败，最后的兜底方案是用 `<view>` 模拟按钮：

```html
<view class="custom-button" bindtap="onSave">
  <view wx:if="{{saving}}" class="btn-loading-icon"></view>
  {{saving ? '保存中...' : '保存'}}
</view>
```

```css
.custom-button {
  width: 100%;
  height: 96rpx;
  line-height: 96rpx;
  text-align: center;
  background: #fa9583;
  color: #ffffff;
  border-radius: 48rpx;
  font-size: 32rpx;
  font-weight: 600;
}

.custom-button:active {
  opacity: 0.8;
}
```

## 已知问题

### glass-easel 组件框架

项目配置了 `"componentFramework": "glass-easel"`，这是微信小程序的新组件系统。可能的影响：

1. 样式隔离机制不同
2. Shadow DOM 相关的样式继承问题
3. 需要确保全局样式能正确应用到所有组件

### @vant/weapp 组件库

项目依赖 `@vant/weapp` 组件库，可能的影响：

1. Vant 可能有全局样式重置
2. 使用 `van-icon` 等组件时可能引入额外样式
3. 需要确保自定义按钮样式优先级高于 Vant

## 测试验证

完成修改后，测试以下场景：

1. **正常点击**
   - 点击按钮时应该保持橙色背景（#fa9583）
   - 文字应该保持白色
   - 透明度应该变为 0.8

2. **Loading 状态**
   - 背景色应该保持橙色
   - 显示旋转的 loading icon
   - 按钮应该禁用无法点击

3. **禁用状态**
   - 背景色应该保持橙色，透明度 0.6
   - 无法点击

4. **快速连续点击**
   - 应该只触发一次请求
   - 视觉上保持橙色
